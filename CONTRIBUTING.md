# Contributing to SupaNexus

Thanks for your interest in contributing to SupaNexus!

We welcome contributions from developers who want to improve AI infrastructure and developer tools.

## How to contribute

### 1. Fork the repository

Create your own fork of this repository.

### 2. Create a branch

Create a new branch for your changes:

```bash
git checkout -b feature/your-feature-name
3. Make changes
Improve the code, documentation, examples, or fix bugs.
4. Submit a Pull Request
Open a Pull Request and describe:
What changed
Why the change is needed
Any testing performed
Contribution areas
We especially welcome:
API examples
SDK improvements
Documentation improvements
Bug reports
Feature suggestions
Thank you for helping improve SupaNexus!
